4  Hybrid models

Work in progress…

So far, all our models have lived in the world of finite sets: every wire carried a variable with finitely many values, and every kernel was specified by a finite table of numbers. But many quantities we care about take continuous values. In this chapter, we extend the string-diagrammatic framework to handle continuous and mixed-type variables.

We introduce the theory gradually. First, we sketch how kernels generalize beyond finite sets, and why density functions are the practical tool for specifying them. Next, we introduce a small probabilistic programming library, WeightedSampling.torch, that automates the weighted sampling procedure from the previous chapter. We then develop a family of parametric regression kernels — the standard building blocks for models with continuous and mixed-type variables. Finally, we compose these kernels into a concrete Swiss health model and demonstrate forward sampling and conditioning.

4.1 General kernels

4.1.1 Motivation

4.1.2 Events

In the introduction we defined an event as any subset \(E \subseteq \Omega\) of a finite sample space \(\Omega\), and observed that logical operations on events correspond to set operations: “not \(E\)” is the complement \(E^\text{c}\), “\(E_1\) and \(E_2\)” is the intersection \(E_1 \cap E_2\), and “\(E_1\) or \(E_2\)” is the union \(E_1 \cup E_2\).

When the sample space is infinite — say \(\Omega = \mathbb{R}\) — we need to be more careful. It turns out that there is no way to consistently assign probabilities to every subset of \(\mathbb{R}\). Instead, we fix a collection \(\mathcal{E}\) of subsets that we agree to treat as events, and only assign probabilities to those.

Which subsets should count? The collection \(\mathcal{E}\) should be rich enough that every event we could want to express is included, and it should be closed under the logical operations we rely on:

  1. Tautology and contradiction. The entire space \(\Omega\) (“something happens”) and the empty set \(\varnothing\) (“nothing happens”) are events.
  2. Complement. If \(E\) is an event, then “not \(E\)”, i.e. \(E^\text{c}\), is also an event.
  3. Sequential unions. If \(E_1, E_2, E_3, \ldots\) is a sequence of events, then \(\bigcup_{n=1}^{\infty} E_n\) is also an event.

The third rule says that if each \(E_n\) is a meaningful event, then “at least one of them holds” should be a meaningful event too — it is the logical “there exists.” Together with complements, it also gives us “all of them hold”: by De Morgan’s law, \(\bigcap_n E_n = \bigl(\bigcup_n E_n^\text{c}\bigr)^\text{c}\), which is the logical “for all.” Finite unions and intersections are the special case where all but finitely many \(E_n\) are \(\Omega\) or \(\varnothing\).

A collection \(\mathcal{E}\) of subsets of \(\Omega\) satisfying these three rules is called a \(\sigma\)-algebra, and its elements are called events.

Definition 4.1 A measurable space is a pair \((\Omega, \mathcal{E})\) consisting of a set \(\Omega\) and a \(\sigma\)-algebra \(\mathcal{E}\) on \(\Omega\). We call the elements of \(\mathcal{E}\) the events of \((\Omega, \mathcal{E})\). When we refer to a measurable space by a single letter, such as \(X\), we write \(\mathcal{E}_X\) for its \(\sigma\)-algebra.

Example 4.2 (Events on the real line) On \(\Omega = \mathbb{R}\), start with the closed intervals \([a, b]\) for all \(a \leq b\) and close under the three rules above. The resulting collection of events is called the Borel \(\sigma\)-algebra \(\mathcal{B}(\mathbb{R})\). It contains every open set, closed set, and interval. This is the collection we will always use when a wire carries a real-valued variable.

4.1.3 Measures

In the introduction we defined a probability measure on a finite set \(\Omega\) by two properties: normalization (\(p(\varnothing) = 0\) and \(p(\Omega) = 1\)) and additivity (\(p(E_1 \cup E_2) = p(E_1) + p(E_2)\) whenever \(E_1\) and \(E_2\) are mutually exclusive).

The same idea carries over to a general measurable space \((\Omega, \mathcal{E})\): a probability measure is a function \(p : \mathcal{E} \to [0,1]\) that assigns a probability to every event, satisfying normalization and additivity. The one new requirement is that additivity must extend from pairs to sequences of mutually exclusive events: if \(E_1, E_2, E_3, \ldots\) are pairwise disjoint, then \[ p\Bigl(\bigcup_{n=1}^{\infty} E_n\Bigr) = \sum_{n=1}^{\infty} p(E_n). \]

Why is it reasonable? It is equivalent to requiring that probability be continuous at 0: if \(E_1 \supseteq E_2 \supseteq E_3 \supseteq \cdots\) is a decreasing sequence of events that shrinks to nothing (\(\bigcap_n E_n = \varnothing\)), then \(p(E_n) \to 0\). In other words, if we iteratively shrink an event until nothing remains, its probability should decrease to zero.

Definition 4.3 A probability measure on a measurable space \((\Omega, \mathcal{E})\) is a function \(p : \mathcal{E} \to [0,1]\) satisfying:

  1. Normalization. \(p(\varnothing) = 0\) and \(p(\Omega) = 1\).
  2. Countable additivity. If \(E_1, E_2, E_3, \ldots \in \mathcal{E}\) are pairwise disjoint, then \(p\bigl(\bigcup_{n=1}^\infty E_n\bigr) = \sum_{n=1}^\infty p(E_n)\).

The triple \((\Omega, \mathcal{E}, p)\) is called a probability space.

4.1.4 Kernels

In the chapter on discrete graphical models we defined a discrete kernel \(f : X \kernel Y\) between finite sets by specifying a non-negative number \(f(y \mid x)\) for each input \(x \in X\) and output \(y \in Y\). We can equivalently describe \(f\) in terms of events: for any subset \(B \subseteq Y\), set \[ f(B \mid x) := \sum_{y \in B} f(y \mid x). \] This gives us the total weight that \(f\) assigns to the event \(B\), given input \(x\). The values on individual points are recovered by taking \(B = \{y\}\).

The event-based formulation generalizes to infinite spaces where it in no longer possible to assign meaningful values to individual points. Thus, a general kernel \(k : X \kernel Y\) assigns a non-negative number \(k(B \mid x)\) to each input \(x\) and each event \(B \in \mathcal{E}_Y\).

Definition 4.4 A kernel \(k : X \kernel Y\) between measurable spaces \((X, \mathcal{E}_X)\) and \((Y, \mathcal{E}_Y)\) assigns to each input \(x \in X\) and each event \(B \in \mathcal{E}_Y\) a non-negative number \(k(B \mid x)\), such that:

  1. For each fixed \(x \in X\), the function \(B \mapsto k(B \mid x)\) is a measure on \((Y, \mathcal{E}_Y)\).
  2. For each fixed \(B \in \mathcal{E}_Y\), the function \(x \mapsto k(B \mid x)\) is measurable.

If \(k(Y \mid x) = 1\) for all \(x\), we call \(k\) a probability kernel. We call \(k\) finite if there is a uniform bound \(r\) such that \(k(Y \mid x) \leq r\) for all \(x \in X\). We will always assume that kernels are finite.

Condition 1 is the substantive requirement: each input produces a measure on the output space. Condition 2 is a technical regularity condition ensuring that the kernel interacts well with the \(\sigma\)-algebras. All kernels we construct in practice will satisfy it automatically, so we will not check it explicitly.

4.1.5 Density functions

A convenient way to specify a kernel is through a density function that describes how weight is spread across the output space.

Continuous outputs. Consider a kernel \(k : X \kernel \mathbb{R}\) whose output is a real-valued variable. For each input \(x\), suppose we have a non-negative function \(y \mapsto l_k(y \mid x)\) whose graph is a curve over the real line. We think of \(l_k(y \mid x)\) as the weight per unit length that \(k\) places near the output value \(y\). The total weight assigned to an event \(B \in \mathcal{E}_Y\) is then the area under this curve above \(B\):

Mathematically, this area is given by the \[ k(B \mid x) = \int_B l_k(y \mid x) \, dy. \] We call \(l_k\) the density of \(k\); the precise definition will follow shortly. For a probability kernel, the total area under the curve equals 1. Note that a single point \(\{y\}\) has zero width and therefore zero area: \(k(\{y\} \mid x) = 0\). For continuous variables, individual outcomes always have probability zero.

Example 4.5 The Gaussian (or normal) density with mean \(\mu\) and variance \(\sigma^2\) is \[ l(y \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\Bigl(-\frac{(y - \mu)^2}{2\sigma^2}\Bigr). \] We write \(\mathsf{Normal}(\mu, \sigma^2)\) for the probability measure with this density — its graph is the familiar bell curve, centered at \(\mu\) with spread controlled by \(\sigma^2\). Since the total area is 1 for every choice of \((\mu, \sigma^2)\), varying the inputs defines a probability kernel \(k : \mathbb{R} \times \mathbb{R}_{>0} \kernel \mathbb{R}\).

Discrete outputs. In the discrete setting, each output value \(y\) carries a weight \(l_k(y \mid x)\), which we can picture as a bar of that height. The total weight on an event \(B\) is the sum of bar heights:

In formulas, the total weight on \(B\) is \[ k(B \mid x) = \sum_{y \in B} l_k(y \mid x). \] This is exactly the formula from the beginning of the previous section: the values \(f(y \mid x)\) that defined a discrete kernel in the chapter on discrete graphical models are precisely its density. Since a discrete kernel is completely determined by its density and vice versa, we treated the two interchangeably in the discrete setting. In the continuous case this identification breaks down, because not all kernels have densities.

Base measures and densities. In both cases above, the kernel is determined by integrating a non-negative function against a fixed measure on the output space: Lebesgue measure (length / area) in the continuous case, counting measure (each point has mass 1) in the discrete case. We call this fixed measure the base measure and the function the density.

Definition 4.6 Let \(\nu\) be a measure on the output space \(Y\). A non-negative function \(l_k(y \mid x)\) is a density of the kernel \(k : X \kernel Y\) with respect to \(\nu\) if \[ k(B \mid x) = \int_B l_k(y \mid x) \, \nu(dy) \] for every \(x \in X\) and every event \(B \in \mathcal{E}_Y\).

4.1.6 String diagrams carry over

The string-diagrammatic language from the chapter on discrete graphical models extends to general kernels with almost no changes. We briefly indicate what stays the same and what requires care.

Deterministic functions. A measurable function \(f : X \to Y\) defines a kernel by \[ k_f(B \mid x) := \ivmark{f(x) \in B}, \] which assigns full weight to the unique output \(f(x)\). The structural kernels \(\id\), \(\swap\), \(\cp\), and \(\del\) are all deterministic. Hence, their formulas are literally the same as before, with the Iverson bracket \(\ivmark{y = f(x)}\) replaced by \(\ivmark{f(x) \in B}\).

Composition. Sequential composition of \(k : X \kernel Y\) and \(k' : Y \kernel Z\) is defined by replacing the sum over \(Y\) with an integral: \[ (k \then k')(B \mid x) := \int_Y k'(B \mid y) \, k(dy \mid x). \] When \(Y\) is a finite set, the integral reduces to the familiar sum \(\sum_{y \in Y} k'(B \mid y)\, k(y \mid x)\). Parallel composition is characterized by its values on product events: \[ (k_1 \otimes k_2)(B_1 \times B_2 \mid x_1, x_2) = k_1(B_1 \mid x_1) \cdot k_2(B_2 \mid x_2). \] This formula only specifies the kernel on “rectangles” \(B_1 \times B_2\), but a standard extension result guarantees that these values determine the kernel on all events in the product space (see the box below for details).

NoteProduct \(\sigma\)-algebras and product measures

When two measurable spaces \((X, \mathcal{E}_X)\) and \((Y, \mathcal{E}_Y)\) are combined, their product space \(X \times Y\) carries the product \(\sigma\)-algebra \(\mathcal{E}_X \otimes \mathcal{E}_Y\), defined as the smallest \(\sigma\)-algebra containing all rectangles \(B_1 \times B_2\) with \(B_1 \in \mathcal{E}_X\) and \(B_2 \in \mathcal{E}_Y\). This \(\sigma\)-algebra contains many events beyond rectangles — for instance, discs in \(\mathbb{R}^2\) — but a finite measure that is defined consistently on rectangles extends uniquely to the full product \(\sigma\)-algebra. This is why the formula for parallel composition, stated only on rectangles, determines the kernel on all product events.

The same principle gives us product measures. Given measures \(\nu_U\) on \(U\) and \(\nu_V\) on \(V\), the product measure \(\nu_U \otimes \nu_V\) is the unique measure on the product space \(U \times V\) satisfying \[ (\nu_U \otimes \nu_V)(B_1 \times B_2) = \nu_U(B_1) \cdot \nu_V(B_2). \] For instance, Lebesgue measure on \(\mathbb{R}^2\) (area) is the product of Lebesgue measure on \(\mathbb{R}\) (length) with itself. Product measures appear naturally when a kernel has multiple outputs: if each output has a base measure, the joint base measure is their product. This is the setting used in the graphical conditioning formula for multiple outputs below.

Algebraic laws. All the algebraic laws verified in the discrete setting continue to hold for general kernels. The proofs are the same calculations, with sums replaced by integrals. In particular, any two diagrams that could be deformed into each other in the discrete setting still represent the same kernel.

Conditional independence. The graphical test for conditional independence from the conditioning chapter remains valid for general kernels.

Graphical conditioning. Pre-conditioning on an input works exactly as before: given a kernel \(g : X \otimes Y \kernel U\), fixing \(X = \bar{x}\) yields \(g_{\mid X = \bar{x}}(B \mid y) := g(B \mid \bar{x}, y)\). This is still a well-defined kernel.

Pre-conditioning on an output generalizes the discrete formula from the conditioning chapter. There, for a discrete kernel \(g : X \kernel U \otimes V\), pre-conditioning on \(U = \bar{u}\) meant plugging \(\bar{u}\) into the first argument: \(g_{\mid U = \bar{u}}(v \mid x) = g(\bar{u}, v \mid x)\). Since the values of a discrete kernel are exactly its density with respect to counting measure, this is the same as plugging \(\bar{u}\) into the density. The same idea works in general.

Suppose \(g : X \kernel U \otimes V\) has density \(l_g(u, v \mid x)\) with respect to a product base measure \(\nu_U \otimes \nu_V\) (see the box above for what this means). Pre-conditioning on \(U = \bar{u}\) plugs \(\bar{u}\) into the density, giving the kernel with density \(l_g(\bar{u}, v \mid x)\): \[ g_{\mid U = \bar{u}}(B \mid x) = \int_B l_g(\bar{u}, v \mid x) \, \nu_V(dv). \]

If \(g : X \kernel U\) has density \(l_g\) and we fix its only output \(U = \bar{u}\), there are no remaining variables to integrate over. The resulting kernel \(g_{\mid U = \bar u} : X \kernel I\) assigns each \(x \in X\) the likelihood weight \(l_g(\bar{u} \mid x)\). This is the case that arises most often in practice.

4.2 Parametric kernels

In the discrete setting, a kernel \(f : X \kernel Y\) was fully specified by a finite table of values \(f(y \mid x)\). When the input or output space is infinite, we need a formula instead: a parametric family that fixes the functional form of the density and lets a finite collection of parameters pin down which density each input selects.

Consider the Gaussian family from Example 4.5. If we let the mean depend on an input \(x\) through the function \(\mu = \alpha_0 + \alpha_1 x\), then three parameters \(\alpha_0\), \(\alpha_1\), and \(\sigma^2\) determine a kernel \(k : \mathbb{R} \kernel \mathbb{R}\): \[ l_k(y \mid x) = l_{\mathsf{Normal}}(y \mid \alpha_0 + \alpha_1 x,\; \sigma^2). \] For every value of \(x\), this formula produces a valid Gaussian density for \(y\). Hence, we have reduced the problem of specifying a kernel to specifying a finite number of parameters. This comes at the cost of expressiveness: kernels in this family can only produce Gaussian samples with means that depend linearly on \(x\).

4.2.1 Constructing kernels

Our strategy for building kernels between arbitrary spaces is compositional. Every kernel we construct has the form \[ X \xrightarrow{\; g \;} \Theta \xrightarrow{\; k_{\text{base}} \;} Y \xrightarrow{\; f \;} Z, \] or, in string-diagram notation, \(k = k_g \then k_{\text{base}} \then k_f\). Three ingredients are chosen independently:

  1. A base family \(k_{\text{base}} : \Theta \kernel Y\) — a standard parametric family of distributions that does all the stochastic work.
  2. An input transformation \(g : X \to \Theta\) — a deterministic function that computes valid parameters from whatever inputs are given.
  3. An output transformation \(f : Y \to Z\) — a deterministic function that redirects the base family’s output to the desired target space.

Either deterministic map can be the identity when no transformation is needed. We now discuss each ingredient in turn.

Base families. Each base family is the simplest adequate model for one common output type:

The Gaussian family is the default for real-valued outputs; the Bernoulli family is the unique distribution on \(\{0,1\}\); and the Poisson family is the standard model for counts. Other families — Gamma (\(\mathbb{R}_{>0}\)), negative binomial (\(\mathbb{N}_0\)), Beta (\((0,1)\)) — can be slotted into the same pattern when needed.

Input transformations. The input transformation \(g : X_1 \otimes \cdots \otimes X_n \to \Theta\) maps the inputs into the parameter space \(\Theta\) of the base family. We build it in two steps: \[ X_1 \otimes \cdots \otimes X_n \xrightarrow{\;g_{\text{lin}}\;} \mathbb{R} \xrightarrow{\;\varphi\;} \Theta. \]

The first step is a linear predictor \(g_{\text{lin}}\) that reduces all inputs to a single real number: \[ \eta \;=\; g_{\text{lin}}(x_1, \ldots, x_n) \;=\; \alpha_0 + \alpha_1 x_1 + \cdots + \alpha_n x_n. \] This accepts any mix of discrete and continuous inputs: a binary input \(x_j \in \{0,1\}\) switches its coefficient on or off, while a continuous input contributes proportionally.

The second step is a response map \(\varphi : \mathbb{R} \to \Theta\) that sends \(\eta\) into the parameter space of the chosen base family. When \(\Theta = \mathbb{R}\) (as for the Gaussian mean), this is just the identity; when \(\Theta\) is a strict subset of \(\mathbb{R}\), we need a map that lands in the right space:

The full input transformation is \[ g = \varphi \circ g_{\text{lin}}. \] Nothing in the construction requires the first step to be linear: we can replace it with nonlinear features, spline bases, or a neural network without changing anything else. In string-diagrammatic terms, only the deterministic kernel \(k_g\) changes; the base family and output transformation are unaffected.

NoteConnection to generalized linear models

When the input transformation has the form \(g = \varphi \circ g_{\text{linear}}\) and the base family belongs to the exponential family, statisticians call the resulting kernel a generalized linear model (GLM). In that literature, \(\varphi^{-1}\) is called the link function and \(\varphi\) the response function or inverse link. Linear regression, logistic regression, and Poisson regression are the three canonical GLMs, corresponding to the three base families above with identity, sigmoid, and exponential maps respectively.

Output transformations. To reach output spaces beyond \(\mathbb{R}\), \(\{0,1\}\), and \(\mathbb{N}_0\), we postcompose with a deterministic function \(f : Y \to Z\):

For example, postcomposing a Gaussian kernel with \(\exp\) gives a log-normal distribution on \(\mathbb{R}_{>0}\) (Section 4.2.5). Postcomposing with the sigmoid gives a logit-normal distribution on \((0,1)\). The thresholding map \(n \mapsto \mathbb{1}[n > 0]\) collapses a Poisson output to a binary indicator, the basis of hurdle models.

We now illustrate the construction on each of the three base families.

4.2.2 Linear regression kernel

A linear regression kernel \(k : X_1 \otimes \cdots \otimes X_n \kernel \mathbb{R}\) models a real-valued output as a Gaussian whose mean depends linearly on the inputs: \[ l_k(y \mid x_1, \ldots, x_n) = l_{\mathsf{Normal}}(y \mid \eta,\; \sigma^2), \qquad \eta = \alpha_0 + \alpha_1 x_1 + \cdots + \alpha_n x_n. \] The output is a bell curve centred at the predicted value \(\eta\). The variance \(\sigma^2\) controls the spread of this curve and does not depend on the inputs, so it represents the irreducible noise that remains even when all inputs are known. Each coefficient \(\alpha_j\) tells us how much a one-unit increase in \(x_j\) shifts the centre of the output distribution, with all other inputs held fixed. In particular, \(\mathbb{E}[Y \mid x] = \eta\), so the inputs affect the output additively: changing \(x_j\) by \(\Delta\) shifts the expected output by \(\alpha_j \Delta\).

4.2.3 Logistic regression kernel

A logistic regression kernel \(k : X_1 \otimes \cdots \otimes X_n \kernel \{0,1\}\) models a binary output. The sigmoid response map (Table 4.2) converts a linear predictor into a valid Bernoulli probability: \[ k(y = 1 \mid x_1, \ldots, x_n) = \sigma(\eta), \qquad \eta = \beta_0 + \beta_1 x_1 + \cdots + \beta_n x_n. \] The output distribution is fully described by \(p = \sigma(\eta)\): the output is \(1\) with probability \(p\) and \(0\) with probability \(1-p\). Because \(\sigma\) is a nonlinear squashing function, the inputs do not affect \(p\) additively. Instead, they act additively on the log-odds scale: \(\log\!\bigl(p/(1{-}p)\bigr) = \eta\), so increasing \(x_j\) by one unit shifts the log-odds by \(\beta_j\), or equivalently multiplies the odds by \(e^{\beta_j}\). When \(\eta\) is near \(0\) (where \(\sigma\) is approximately linear), a small change in an input produces a roughly proportional change in probability; when \(|\eta|\) is large, the probability is already close to \(0\) or \(1\) and the same change has little effect.

4.2.4 Categorical regression kernel

A categorical regression kernel \(k : X_1 \otimes \cdots \otimes X_n \kernel \{1, \ldots, K\}\) extends logistic regression from two classes to \(K > 2\) unordered values. Each class \(j\) gets its own linear predictor \(\eta_j = \beta_{j,0} + \beta_{j,1} x_1 + \cdots + \beta_{j,n} x_n\), and softmax converts the vector \((\eta_1, \ldots, \eta_K)\) into a probability distribution: \[ k(y = j \mid x_1, \ldots, x_n) = \frac{e^{\eta_j}}{\sum_{k=1}^K e^{\eta_k}}. \] The output distribution assigns a probability to each of the \(K\) classes; these probabilities are positive and sum to \(1\). The class with the largest \(\eta_j\) is the most probable, but the other classes retain positive probability. Each coefficient \(\beta_{j,i}\) controls how input \(x_i\) shifts the log-odds of class \(j\) relative to the others: increasing \(x_i\) by one unit multiplies the odds of class \(j\) (relative to any fixed reference class) by \(e^{\beta_{j,i}}\). For \(K = 2\), writing \(\eta = \eta_1 - \eta_2\) recovers the logistic regression kernel.

4.2.5 Log-normal regression kernel

A log-normal regression kernel models a strictly positive, right-skewed output by combining a Gaussian base family with the output transformation \(f = \exp\) (Table 4.3): \[ l_k(z \mid x_1, \ldots, x_n) = l_{\mathsf{LogNormal}}(z \mid \eta,\; \tau^2), \qquad \eta = \gamma_0 + \gamma_1 x_1 + \cdots + \gamma_n x_n. \] Equivalently, \(Z = e^{Y}\) where \(Y \sim \mathsf{Normal}(\eta, \tau^2)\). Since \(\exp\) maps \(\mathbb{R}\) onto \(\mathbb{R}_{>0}\), the output is automatically positive. Its distribution is right-skewed: the median is \(e^{\eta}\), and the parameter \(\tau^2\) controls how spread out and heavy-tailed the distribution is. Because the linear predictor \(\eta\) operates on the log scale, the inputs affect the output multiplicatively: increasing \(x_j\) by one unit multiplies the median by \(e^{\gamma_j}\).

4.2.6 Poisson regression kernel

A Poisson regression kernel models a count-valued output (\(y \in \mathbb{N}_0\)). The exponential response map (Table 4.2) converts a linear predictor into a valid Poisson rate \(\lambda > 0\): \[ k(y \mid x_1, \ldots, x_n) = l_{\mathsf{Poisson}}(y \mid \lambda), \qquad \lambda = e^{\eta}, \qquad \eta = \delta_0 + \delta_1 x_1 + \cdots + \delta_n x_n. \] The output distribution places a probability bar at each non-negative integer, concentrated around \(\lambda\): the expected count is \(\mathbb{E}[Y \mid x] = \lambda = e^{\eta}\), and the variance equals \(\lambda\) as well — so higher counts come with more spread. As with the log-normal kernel, the inputs act multiplicatively: increasing \(x_j\) by one unit multiplies the expected count by \(e^{\delta_j}\).

4.3 The Swiss health model

We now apply the framework to a concrete example: a model of Swiss health variables relating lifestyle factors to disease risk and healthcare costs. The model is assembled entirely from the parametric kernels introduced above, composed via the string-diagrammatic operations of Section 4.1.6. We describe the variables and their relationships, instantiate the kernels with parameters calibrated to Swiss population statistics, and demonstrate forward sampling and conditioning using WeightedSampling.torch.

The model relates six variables:

The causal story runs as follows. Smoking status, age, and physical activity are root variables with no parents in the model. Together, they influence BMI through a linear regression kernel. BMI in turn influences diabetes risk through a logistic regression kernel. Finally, diabetes status and BMI jointly determine healthcare costs through a log-normal regression kernel. The graph is a directed chain with one fan-out: BMI feeds into both the diabetes kernel and the cost kernel.

The parameters appearing below are grounded in publicly available Swiss summary statistics. Where a parameter corresponds directly to a published statistic (a prevalence, a mean, or a rate), we read its value from the source; where possible, we derive regression coefficients from published relative risks. The remaining coefficients are calibrated so that the model’s marginal distributions reproduce the published target values. In the next chapter, we explain how parameter estimates are obtained systematically from data.

4.3.1 Root distributions

The three root variables have no parents, so they are specified by marginal distributions (kernels \(I \kernel X\) with trivial input):

  • Smoking \(S \sim \mathsf{Bernoulli}(0.27)\). The SGB 2022 reports that 27.1% of men and 20.8% of women smoke daily or occasionally; we use \(0.27\) as a round approximation.
  • Age \(A \sim \mathsf{Normal}(42, 17^2)\). The Swiss median age is 42.7 years (BFS STATPOP). The standard deviation of 17 is chosen to approximate the adult age distribution.
  • Physical activity \(P \sim \mathsf{Normal}(5, 2^2)\), measured in hours of sport per week. Sport Schweiz 2020 reports that 51% of adults are “trained” (\(\geq 3\) hours/week), 27% “sufficiently active,” 16% “partly active,” and 6% “inactive.”

4.3.2 The BMI kernel (linear regression)

BMI is a continuous variable influenced by a mix of discrete and continuous parents — exactly the setting for which the linear regression kernel (Section 4.2.2) is designed: \[ B \mid S, A, P \;\sim\; \mathsf{Normal}(\alpha_0 + \alpha_S\, S + \alpha_A\, A + \alpha_P\, P,\; \sigma^2). \]

NoteParameter sourcing — BMI kernel
  • Intercept \(\alpha_0 = 25.0\): set so that \(\mathbb{E}[B] \approx 25.3\) at the population means, matching the WHO age-standardized estimate of Switzerland’s mean BMI.
  • Smoking slope \(\alpha_S = -0.5\): epidemiological studies consistently find that current smokers have slightly lower BMI than non-smokers, owing to nicotine’s appetite-suppressive effect. A meta-analysis (Dare et al., 2015, BMJ Open 5: e008330) reports that current smokers have BMI roughly 0.3–0.7 kg/m² lower than never-smokers after adjusting for confounders.
  • Age slope \(\alpha_A = 0.05\): the SGB 2022 shows overweight-plus-obesity prevalence rising from roughly 30% in the 25–34 age group to 55% at ages 55–64. A slope of 0.05 BMI units per year produces a 1.5-unit increase over 30 years, consistent with this gradient.
  • Activity slope \(\alpha_P = -0.3\): the NCD cost report (Stucki et al., 2025, Table 28) reports a physical inactivity → obesity odds ratio of 1.49 (Bell et al., 2014), confirming the direction. The magnitude is approximate.
  • Residual standard deviation \(\sigma = 3.8\): calibrated so that the model produces approximately 43% overweight (BMI \(\geq\) 25) and 12% obese (BMI \(>\) 30), matching SGB 2022 rates.

4.3.3 The diabetes kernel (logistic regression)

Diabetes status is binary and depends on BMI — the setting for the logistic regression kernel (Section 4.2.3): \[ D \mid B \;\sim\; \mathsf{Bernoulli}\bigl(\sigma(\beta_0 + \beta_1\, B)\bigr). \]

NoteParameter sourcing — diabetes kernel
  • Intercept \(\beta_0 = -6.7\): calibrated so that the marginal diabetes prevalence at average BMI matches the Swiss rate. The IDF Diabetes Atlas reports 5.3% (ages 20–79). The SGB 2022 reports 6.9% of men and 4.0% of women, giving a combined rate of approximately 5.4%. The Obsan diabetes report (pp. 47–49) compiles prevalence estimates from multiple Swiss data sources (SGB, Helsana, CoLaus, SAPALDIA), all converging on 5–7%.
  • Slope \(\beta_1 = 0.15\): the Stucki et al. (2025) NCD cost report compiles relative risks for diabetes type 2: overweight (BMI 25–30) vs. normal weight gives RR = 2.25 (men) / 2.30 (women); obesity (BMI \(\geq\) 30) vs. normal weight gives RR = 5.50 (men) / 7.00 (women). The CoLaus study (Kaiser et al., 2012) reports multivariable-adjusted odds ratios: overweight OR = 1.51 (1.07–2.12), obese OR = 5.14 (3.39–7.78). Approximating a log-linear relationship from the Stucki RRs gives \(\beta_1 \approx \log(2.25)/5.5 \approx 0.15\).

4.3.4 The cost kernel (log-normal regression)

Annual healthcare costs are strictly positive and right-skewed — the setting for the log-normal regression kernel (Section 4.2.5). Costs depend on both diabetes status and BMI: \[ \log C \mid D, B \;\sim\; \mathsf{Normal}(\gamma_0 + \gamma_D\, D + \gamma_B\, B,\; \tau^2). \]

NoteParameter sourcing — cost kernel
  • Intercept \(\gamma_0 = 7.5\): calibrated so that the median cost for a non-diabetic adult at average BMI is roughly CHF 3,900. For reference, total Swiss healthcare expenditure in 2022 was CHF 869 per person per month (CHF 10,428 per year; BFS Taschenstatistik 2025, p. 32).
  • Diabetes slope \(\gamma_D = 0.65\): the Obsan diabetes report (p. 47) cites Helsana data showing direct healthcare costs of CHF 8,239/year per diabetic patient (2011), roughly twice the non-diabetic baseline. Taking the log ratio gives \(\gamma_D \approx \ln(8239/3900) \approx 0.75\); we use the slightly conservative value \(0.65\) to account for the fact that not all of the cost differential is attributable to diabetes status alone.
  • BMI slope \(\gamma_B = 0.03\): encodes the qualitatively correct direction (higher BMI increases costs). The NCD cost report attributes 70% of diabetes type 2 productivity losses to overweight/obesity, confirming the strong cost linkage. The per-unit magnitude is approximate.
  • Dispersion \(\tau = 0.6\): reflects the typically right-skewed cost distribution.

4.3.5 Composing the full model

4.3.6 Forward sampling

We implement the full model in WeightedSampling.torch by composing the root distributions and regression kernels:

import torch
import torch.distributions as dist
from weighted_sampling import model, sample, observe, summary, expectation
@model
def swiss_health():
    # --- Root distributions ---
    S = sample("S", dist.Bernoulli(0.27))          # smoking
    A = sample("A", dist.Normal(42.0, 17.0))       # age
    P = sample("P", dist.Normal(5.0, 2.0))         # activity (hours/week)

    # --- BMI kernel (linear regression) ---
    eta_B = 25.0 + (-0.5) * S + 0.05 * A - 0.3 * P
    B = sample("B", dist.Normal(eta_B, 3.8))

    # --- Diabetes kernel (logistic regression) ---
    eta_D = -6.7 + 0.15 * B
    D = sample("D", dist.Bernoulli(torch.sigmoid(eta_D)))

    # --- Cost kernel (log-normal regression) ---
    eta_C = 7.5 + 0.65 * D + 0.03 * B
    C = sample("C", dist.LogNormal(eta_C, 0.6))


result = swiss_health(num_particles=10_000)
print(summary(result))
