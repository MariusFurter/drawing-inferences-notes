Introduction

NotePrerequisites: Python libraries

This exercise uses:

  • pandas — tabular data.
  • numpyro and jax — Bayesian inference via MCMC.
  • matplotlib — plotting.

Install with pip install pandas numpyro jax matplotlib if needed.

The dataset

  • stroke_train_prepared.csv — training data (4088 patients)
  • stroke_test_prepared.csv — test data (1022 patients)
Variable Values Encoding
age young (<35), middle (35–65), senior (≥65) 0, 1, 2
hyp no, yes 0, 1
log_glucose \(\log(\text{avg\_glucose\_level})\), in \(\log\) mg/dL continuous
heart_disease no, yes 0, 1

Task 1. A hybrid causal model

Task 1a. Draw the string diagram for the hybrid model (with the optional heart-disease box, or without if Task 4 is skipped).

TipSolution (Task 1a)

Task 1b. Suppose we observe a fully complete dataset \((\bar a_i, \bar h_i, \bar g_i, \bar d_i)_{i=1}^N\). Add a separate parameter prior to each box and condition on the data. Argue that the resulting model factors into independent parallel parts, one per kernel.

TipSolution (Task 1b)

Task 2. Fit the discrete boxes analytically

Task 2a. Fit the age generator using a Dirichlet–Categorical update. Use a uniform \(\mathrm{Dirichlet}(1, 1, 1)\) prior. Report the posterior mean and a 90% credible interval for each \(p_a := P(\text{age} = a)\).

TipSolution (Task 2a)

Task 2b. Fit hyp | age row by row using independent Dirichlet–Categorical updates. Use a \(\mathrm{Dirichlet}(1, 1)\) prior on each row. Report the posterior mean kernel and 90% credible intervals for \(P(\text{hyp}=1 \mid \text{age}=a)\) for each \(a\).

TipSolution (Task 2b)

Task 2c (Optional — derivation). Starting from a \(\mathrm{Beta}(1, 1)\) prior on \(p_a := P(\text{hyp} = 1 \mid \text{age} = a)\) and the Bernoulli likelihood for the \(n_a\) observations of hyp in age category \(a\), derive the posterior in closed form. Conclude with the Dirichlet–Categorical generalization for kernels with more than two output categories.

TipSolution (Task 2c, optional)

Task 3. Fit log_glucose | age, hyp with NumPyro

Task 3a. Implement the cell-mean Normal model in NumPyro and run MCMC. Report the posterior summary (mcmc.print_summary()).

TipSolution (Task 3a)

Task 3b. Plot posterior means and 90% credible intervals for each cell \(\mu_{a,h}\) alongside the empirical cell means as a sanity check.

TipSolution (Task 3b)

Task 3c. Which factor — age or hypertension — has a larger effect on mean log-glucose? Quantify using the posterior of the differences.

TipSolution (Task 3c)

Task 4 (Optional). Fit heart_disease | age, hyp, log_glucose

Task 4a. Fit the logistic-regression model in NumPyro. Report posterior means and 90% credible intervals for all coefficients.

TipSolution (Task 4a)

Task 4b. Interpret the signs of the coefficients. Do age, hypertension, and elevated glucose all contribute positively to heart-disease log-odds?

TipSolution (Task 4b)

Task 5. Missing data, completely at random (MCAR)

Task 5a. Randomly drop ~30% of log_glucose values from the training data (use jax.random.PRNGKey(42) for reproducibility). Confirm the fraction missing.

TipSolution (Task 5a)

Task 5b. Build a joint NumPyro model containing both the log_glu | age, hyp box and the heart | age, hyp, log_glu box. For rows where log_glu is missing, introduce a latent imputed value x_imp via .mask(False) (see practical.qmd, exm-missing-regression). Fit by MCMC.

TipSolution (Task 5b)

Task 5c. Compare the posterior coefficients of the heart model (Task 4) with those obtained from the joint MCAR fit. Are they consistent?

TipSolution (Task 5c)

Task 5d. Make a forest plot of the posterior 90% credible intervals for the imputed log_glu values at the missing positions, with the true (hidden) values overlaid. Mirrors fig-imputation-forest in practical.qmd.

TipSolution (Task 5d)

Task 6. Informative missingness: threshold censoring

Task 6a. Construct the censored dataset by replacing log_glucose with NaN for all rows where log_glucose > c (use \(c = 5.0\)). Report the fraction censored overall and per cell \((a, h)\).

TipSolution (Task 6a)

Task 6b (Naive). Refit the Task 3 cell-mean Normal model dropping the censored rows. Show that the posterior cell means \(\mu_{a,h}\) are biased downward, especially in heavily-censored cells (senior, hypertensive).

TipSolution (Task 6b)

Task 6c (Censored likelihood). Add a numpyro.factor term for each censored row equal to \(\log P(\text{log\_glu} > c \mid \mu_{a,h}, \sigma) = \log(1 - \Phi((c - \mu_{a,h})/\sigma))\). Refit and show the posterior recovers unbiased estimates. Plot the posterior of \(\mu_{2,1}\) for the naive vs. censored vs. full-data models on one axis.

TipSolution (Task 6c)

Task 6d. Contrast Tasks 5 (MCAR) and 6 (threshold censoring): under which mechanism does naive deletion work, and under which does it fail? Explain in terms of the string diagram.
